# Nexus Exchange

Full-stack crypto exchange UI with matching engine, order book, wallets, and real-time WebSocket market data.

**Live demo:** https://nexus-exchange-eight.vercel.app

## Quick start

```bash
npm install
npm run dev
```

| Surface | Command |
|--------|---------|
| Web (Next.js) | `npm run web` |
| API server | `npm run server` |

## Deploy

Production web UI is on Vercel: https://nexus-exchange-eight.vercel.app
